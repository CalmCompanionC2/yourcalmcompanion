What makes Norman different
Five motor system
LRA + ERM layered.
Three precision LRA motors provide directional wave patterns that travel through Norman's body. Two ERM motors add a continuous ambient presence underneath — like an ocean floor beneath the waves. Together they create sensations neither motor type achieves alone.
Choreography
Five motors. One feel.
Three LRA motors sit vertically in Norman's belly — upper, center, lower — each driven by a DRV2605L haptic driver chip via the PCA9548A I2C multiplexer. Two ERM motors provide continuous ambient vibration, modulated independently per mode for a fully layered therapeutic experience.
Squeeze responsive
Norman feels you.
A force-sensitive resistor (FSR) sits beneath a heart-shaped patch on Norman's back, marking exactly where to press. Two modes respond to it. In Responsive Hug, the harder you squeeze, the stronger Norman responds — a proportional haptic conversation. In Box Breathing, holding the patch runs the session and releasing it pauses — so you decide how long the practice lasts.
The Technology · LRA + ERM System
From buzz
to presence.
LRA motors vibrate linearly at a precise resonant frequency — the same technology as premium smartphones — giving them a distinct, textured feel with dozens of individually selectable effects. ERM motors run continuously, producing a softer, fuzzy ambient buzz rather than a sharp pulse. Norman uses LRAs for precise wave choreography, then layers ERM motors underneath as a continuous ambient tide — two different textures, each doing what it does best, combined into one dual-layer haptic architecture designed specifically for nervous system regulation.

Motor Placement · Five Motor System
Five motors.
One body.
Three LRA motors run in a vertical line on Norman's belly — and each mode uses the array differently. In Heartbeat, M2 carries the lub-dub while M1 and M3 add soft resonance around it. In Deep Calm, all three ripple up and down together like a cresting, falling wave. In Box Breathing, the array rises in intensity on the inhale and eases back on the exhale, with the ERM pair ramping right alongside it. Two ERM motors flank the belly, layering a continuous ambient presence beneath the LRA choreography in most modes — sometimes steady, sometimes ramping in sync with the wave — while Heartbeat runs LRA alone for a cleaner, more distinct pulse. Together, the two motor types create a combined sensation neither achieves alone.
